## 数据说明与同意

开始体验前，参与者必须看到数据用途、允许记录项、禁止记录项、保存位置、保存期限和删除方式，并明确选择：

- 同意记录匿名事件；或
- 不同意记录，继续完整体验。

默认不上传研究事件。选择同意后，事件仅保存在当前浏览器，最多 7 天；参与者可随时删除，或在完成页主动下载 JSON 交给研究主持人。不同 Session ID、测试环境和生产环境不得合并为同一身份。

刷新恢复数据与 analytics 分开保存。回答、澄清、选择、手稿和流程状态保存在浏览器 IndexedDB；未完成体验 24 小时后过期，完成档案保留到参与者点击页面底部“删除当前体验的本地数据”或清除本站浏览器数据。该数据不会自动作为 analytics 上传。

允许字段仅包括：随机 Session ID、总体验时间、阶段停留时间、初始肖像、Diff 接受/拒绝、语义碎片去向、是否保留分歧、最终肖像、文稿归宿、是否完成、是否触发降级，以及 Prompt/Adapter/Schema/内容包版本。

禁止保存完整自由输入、用户原话依据、模型完整输入、完整 Prompt、internalExcerpt、API 密钥、身份信息、人格标签和心理诊断。

若测试使用 Live 模式，当前步骤所需的自由输入和上下文会发送给 DeepSeek API 生成候选，但不得进入本项目 analytics 或普通日志。根据 2026-08-10 核对的 [DeepSeek 官方 Context Caching 文档](https://api-docs.deepseek.com/guides/kv_cache)与[官方说明](https://api-docs.deepseek.com/news/news0802/)，磁盘 context cache 默认启用、按账户隔离，未使用缓存通常在数小时至数天内清理；测试主持人必须在测试前披露第三方处理并提醒参与者不要输入敏感身份信息。

## 主持流程

1. 记录测试日期、设备、浏览器、视口、测试 URL、Git commit/build ID 与运行模式。
2. 请参与者阅读数据说明，并在不受诱导的情况下选择同意或拒绝。
3. 不解释作品的“正确答案”，只在技术阻塞时提供帮助。
4. 观察欢迎、肖像序章、三轮审校、精确/朴素对照、语义安放、最终肖像、签名、归宿和 COMPLETE。
5. 记录退出阶段、技术失败、降级和参与者主动提出的困惑。
6. 完成后进行访谈；开放回答写入独立研究笔记，不混入产品 analytics。
7. 若参与者同意，可下载匿名事件 JSON；否则不要求导出。
8. 测试结束后询问是否删除本地研究数据和浏览器体验进度。

## 反馈问题

1. 你最初为什么选择那个“真正的查理”？
2. 体验结束后，你如何描述自己的最终选择？它与开始时有什么不同？
3. 哪一轮最影响你的判断？
4. 精确版和朴素版有什么区别？
5. 语义花束代表什么？
6. 为什么未来查理的签名为空？
7. Agent 是否让你觉得被审判？
8. 哪个环节最像普通聊天机器人？
9. 哪个环节让你觉得 AI 是必要的？
10. 是否误以为原创内容来自原著？

## 最低评估指标

- 完成率：进入 COMPLETE 的有效会话 / 开始体验的有效会话。
- 中位体验时长：完成会话从开始到 COMPLETE 的中位数。
- 各阶段退出率：最后进入该阶段且未完成的会话 / 开始体验的有效会话。
- 原创内容误认率：访谈中误认为原创互动来自原著的人数 / 有效访谈人数。
- 未来签名含义理解率：能区分空签名、拒签和技术不可用的人数 / 有效访谈人数。
- 语义花束理解率：能说明其用于保留无法完整传递意义的人数 / 有效访谈人数。
- Agent 被审判感比例：明确报告被审判感的人数 / 有效访谈人数。
- 真实模型降级率：真实模式中发生 fallback 的能力执行数 / 真实模式能力执行总数。

分析只描述参与者如何表达理解变化及其相关环节，不评价其是否“真正改变”或达到正确理解。
